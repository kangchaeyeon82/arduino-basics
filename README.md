## 1. GPIO

> 메모: GPIO는 프로그래밍이 가능한 핀이다.

<br>

### 뜻

GPIO는 General Purpose Input Output, 우리말로 범용 입출력이라는 뜻이에요.
아두이노 가장자리에 줄지어 있는 핀 중에서, 코드로 할 일을 정해 줄 수 있는 핀을 말해요.

<br>

### 출력으로 쓸지, 입력으로 쓸지

같은 핀이라도 `pinMode()`로 어떻게 쓸지 정해요.

| 코드 | 하는 일 |
|---|---|
| `pinMode(핀, OUTPUT)` | 핀에서 전기를 내보내요 (출력) |
| `pinMode(핀, INPUT)` | 핀에 들어온 전기를 읽어요 (입력) |

<br>

## 2. 디지털 출력

> 메모: 디지털 출력 5V, GND

<br>

### HIGH와 LOW

디지털 출력은 두 가지 상태만 있어요. 켜거나 끄거나.

| 코드 | 핀의 전압 | LED |
|---|---|---|
| `digitalWrite(핀, HIGH)` | 5V | 켜짐 |
| `digitalWrite(핀, LOW)` | 0V (GND) | 꺼짐 |

```cpp
digitalWrite(13, HIGH);  // 13번 핀에 5V → LED 켜기
delay(1000);             // 1초 기다리기
digitalWrite(13, LOW);   // 13번 핀을 0V로 → LED 끄기
```

<br>

### GND

GND(그라운드)는 0V 기준점이에요. 전기는 5V에서 나와 부품을 지나 GND로 돌아와야 해서, GND까지 이어져야 회로가 완성돼요.

<br>

### 직접 해 보니

A0 같은 아날로그 핀도 `digitalWrite`를 쓰면 디지털 출력 핀처럼 쓸 수 있었어요. → [Blink_A0](Blink_A0/Blink_A0.ino)

<br>

## 3. 디지털 입력

> 메모: 같은 노드의 전압을 읽는다. 5V에 가까운지 0V에 가까운지 판단해서 1, 0

<br>

### 노드

노드는 전선으로 이어져서 전압이 같은 부분을 말해요. 아두이노는 핀과 같은 노드에 있는 전압을 재요.

<br>

### 1과 0을 나누는 기준

| 핀의 전압 | 읽은 값 |
|---|---|
| 약 3V 이상 (5V 쪽) | 1 (HIGH) |
| 약 1.5V ~ 3V | 어느 쪽으로 읽힐지 알 수 없음 |
| 약 1.5V 이하 (0V 쪽) | 0 (LOW) |

```cpp
int state = digitalRead(2);  // 2번 핀이 5V 쪽이면 1, 0V 쪽이면 0
```

<br>

## 4. 버튼의 여러 문제점

> 메모: 풀업·풀다운 / 디바운싱 / 상태변화 / 인터럽트

버튼은 꽂기만 하면 될 것 같지만, 제대로 쓰려면 아래 네 가지를 알아야 해요.

<br>

### ① 풀업 · 풀다운

버튼을 안 누르고 있을 때 핀이 5V에도 GND에도 연결되어 있지 않으면, 핀이 떠 있는(floating) 상태가 돼요. 이때는 1과 0이 제멋대로 바뀌어요.

그래서 저항으로 핀을 한쪽 전압에 연결해 둬요.

| 방식 | 연결 | 안 누를 때 | 누를 때 |
|---|---|---|---|
| 풀업 | 저항으로 핀을 5V에 연결 | 1 | 0 |
| 풀다운 | 저항으로 핀을 GND에 연결 | 0 | 1 |
| 내부 풀업 | 아두이노 안의 저항 사용 | 1 | 0 |

```cpp
pinMode(2, INPUT_PULLUP);  // 내부 풀업. 버튼을 2번 핀과 GND 사이에 꽂기만 하면 돼요
```

내부 풀업은 저항을 따로 달지 않아도 돼서 편해요. 대신 누르면 0, 안 누르면 1로 거꾸로 읽혀요.

<br>

### ② 디바운싱

버튼 안의 금속 조각은 누르는 순간 몇 ms 동안 붙었다 떨어졌다를 반복해요. 이걸 바운싱(떨림)이라고 해요.

```
생각한 신호:  ‾‾‾‾‾‾‾|_______________   한 번 눌림
실제 신호:    ‾‾‾‾‾‾‾|_|‾|_|‾|________   여러 번 눌린 것처럼 보임
                     └─ 떨림 ─┘
```

아두이노는 아주 빨라서 이 떨림을 여러 번 누른 걸로 읽어요. 그래서 값이 일정 시간(약 50ms) 그대로일 때만 진짜로 인정하는데, 이걸 디바운싱이라고 해요.

```cpp
if (reading != lastReading) {            // 값이 바뀌면
  lastDebounceTime = millis();           // 바뀐 시각을 기록
}
if (millis() - lastDebounceTime > 50) {  // 50ms 동안 그대로면
  // 진짜 상태로 인정
}
```

**직접 해 보니**
- 디바운싱을 빼니 한 번만 눌러도 LED가 여러 번 바뀌었어요.
- 200ms로 늘리니 짧게 톡 누르면 반응하지 않고, 꾹 눌러야 바뀌었어요.
- 20~50ms 정도가 적당했어요.

<br>

### ③ 상태 변화 감지

`loop()`는 1초에 수천 번 돌아요. 그래서 "버튼이 눌려 있으면 1 더하기"로 짜면, 잠깐 누르고 있는 사이에 숫자가 수백, 수천이 돼요.

그래서 현재값과 과거값을 비교해서, 값이 바뀌는 순간에만 한 번 세요.

| 과거값 | 현재값 | 뜻 |
|---|---|---|
| 1 | 0 | 지금 막 눌렀다 (이때만 세기) |
| 0 | 0 | 계속 누르고 있다 |
| 0 | 1 | 지금 막 뗐다 |
| 1 | 1 | 안 누르고 있다 |

```cpp
if (lastReading == HIGH && reading == LOW) {  // 1 → 0으로 바뀐 순간
  pressCount++;
}
lastReading = reading;  // 현재값을 과거값으로 저장
```

<br>

### ④ 인터럽트

`delay(5000)`으로 5초를 기다리는 동안 버튼을 누르면, 아두이노는 5초가 끝날 때까지 알아채지 못해요.

인터럽트를 쓰면 핀 신호가 바뀌는 순간 하던 일을 잠깐 멈추고 정해 둔 함수를 바로 실행해요. 문 앞을 계속 지켜보지 않아도 초인종이 울리면 나가 보는 것과 비슷해요.

```cpp
attachInterrupt(digitalPinToInterrupt(2), buttonISR, FALLING);
//                                    핀    실행할 함수   언제
```

| 언제 | 뜻 (내부 풀업 기준) |
|---|---|
| `FALLING` | 1 → 0, 누르는 순간 |
| `RISING` | 0 → 1, 떼는 순간 |
| `CHANGE` | 누를 때와 뗄 때 모두 |

주의할 점

| 내용 | 이유 |
|---|---|
| 우노는 2번, 3번 핀만 인터럽트 가능 | 다른 핀은 `attachInterrupt`가 안 돼요 |
| 인터럽트에서 바꾸는 변수에는 `volatile` 붙이기 | `loop()`에서 바뀐 값을 제대로 읽기 위해서 |
| 인터럽트 함수 안에서 `Serial`, `delay` 쓰지 않기 | 인터럽트 함수는 짧고 빠르게 끝나야 해요 |

## 5. 아날로그 출력 (PWM)

> 메모: PWM으로 펄스폭 변조를 해 아날로그 값을 표현한다

<br>

### 원리

아두이노 핀은 5V 아니면 0V만 낼 수 있어요. 그래서 LED를 반쯤 밝게 하려면, 아주 빠르게 켰다 껐다 해요. 눈이 그 속도를 따라가지 못해서 중간 밝기로 보여요.

켜져 있는 시간의 비율을 바꿔서 밝기를 조절하는 방법을 PWM(Pulse Width Modulation, 펄스폭 변조)이라고 해요.

```
analogWrite(11, 0)    ________________________   0%    꺼짐
analogWrite(11, 64)   ‾|___‾|___‾|___‾|___‾|___  25%   어둡게
analogWrite(11, 127)  ‾‾|__‾‾|__‾‾|__‾‾|__‾‾|__  50%   반 밝기
analogWrite(11, 191)  ‾‾‾|_‾‾‾|_‾‾‾|_‾‾‾|_‾‾‾|_  75%   밝게
analogWrite(11, 255)  ‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾  100%  최대 밝기
```

<br>

### 쓸 수 있는 핀

- `analogWrite()`에는 0 ~ 255 값을 넣어요.
- 우노에서 PWM이 되는 핀은 숫자 옆에 `~` 표시가 있는 3, 5, 6, 9, 10, 11번이에요.

<br>

### 직접 해 보니

[Blink_Fast](Blink_Fast/Blink_Fast.ino)에서 깜빡이는 간격을 0.1초 → 0.05초 → 0.01초 → 0.005초로 줄여 봤어요. 간격이 짧아질수록 깜빡임이 안 보이더니, 마지막에는 LED가 반쯤 밝게 켜져 있는 것처럼 보였어요. PWM과 같은 원리예요. (`analogWrite`는 이보다 훨씬 빠르게, 1초에 약 490번 켰다 껐다 해요.)

<br>

## 6. 아날로그 입력

> 메모: 아날로그 입력 A0~A5, 같은 노드의 전압을 읽는다

<br>

### 0 ~ 1023

디지털 입력은 1 아니면 0이지만, 아날로그 입력은 0V ~ 5V를 1024단계로 나눠서 읽어요.

| 전압 | `analogRead()` 값 |
|---|---|
| 0V | 0 |
| 2.5V | 약 512 |
| 5V | 1023 |

```cpp
int value = analogRead(A0);            // 0 ~ 1023
float voltage = value * 5.0 / 1023.0;  // 전압(V)으로 바꾸기
```

<br>

### 값 범위 바꾸기 `map()`

가변저항 값(0 ~ 1023)으로 LED 밝기(0 ~ 255)를 조절할 때처럼, 범위가 다르면 `map()`으로 바꿔요.

```cpp
int brightness = map(value, 0, 1023, 0, 255);
```

## 7. 시리얼 통신

<br>

### 하는 일

아두이노가 USB 선으로 컴퓨터에 글자를 보내는 기능이에요. 코드가 제대로 도는지, 센서 값이 얼마인지 화면으로 확인할 때 써요.

```cpp
void setup() {
  Serial.begin(9600);          // 통신 시작, 속도 9600
}

void loop() {
  Serial.print("value: ");     // 출력 (줄 안 바꿈)
  Serial.println(123);         // 출력하고 줄 바꿈
}
```

<br>

### 보는 법

1. 아두이노 IDE 오른쪽 위 돋보기 아이콘(시리얼 모니터)을 눌러요.
2. 오른쪽 아래 속도를 9600 baud로 맞춰요.

코드에 적은 속도와 시리얼 모니터 속도가 다르면 글자가 깨져서 나와요.

## 8. 회로 결선

<br>

### 기본 규칙

- 모든 부품의 GND는 아두이노 GND와 이어져야 해요.
- 브레드보드는 같은 세로줄 5칸끼리 연결되어 있어요. 저항 다리와 LED 다리가 같은 줄에 있어야 서로 이어져요.
- 긴 브레드보드는 옆의 +/− 줄이 가운데에서 끊겨 있는 경우가 있어요.

**직접 해 보니**
신호등을 만들 때 초록은 켜지는데 노랑과 빨강이 안 켜졌어요. 이럴 때는 코드보다 LED 방향, 꽂은 핀 번호, GND 연결을 먼저 확인해요.

<br>

### 가변저항

손잡이를 돌리면 저항값이 바뀌는 부품이고, 다리가 3개예요.

```
   ┌───────────┐
   │  (손잡이)  │
   └─┬───┬───┬─┘
     │   │   │
    5V  A0  GND
```

- 바깥쪽 다리 2개는 5V와 GND에 연결해요. 서로 바꿔 꽂으면 돌리는 방향만 반대가 돼요.
- 가운데 다리는 아날로그 핀(A0 등)에 연결해요.
- 손잡이를 돌리면 가운데 다리의 전압이 0V ~ 5V 사이에서 바뀌어요.

<br>

### LED

```
 핀 ── 저항 220Ω ── 긴 다리(+)  LED  짧은 다리(−) ── GND
```

| 확인할 것 | 이유 |
|---|---|
| 긴 다리(+)는 핀 쪽, 짧은 다리(−)는 GND 쪽 | 거꾸로 꽂으면 켜지지 않아요 |
| 저항 달기 (220Ω ~ 330Ω) | 저항이 없으면 전류가 너무 많이 흘러 LED나 핀이 망가질 수 있어요 |

<br>

### 버튼 (풀업, 풀다운, 내부 풀업)

4발 택트 버튼은 마주 보는 다리끼리 원래 붙어 있어요. 헷갈릴 때는 대각선 위치의 다리 두 개를 쓰면 돼요.

```
  풀업                  풀다운                내부 풀업
  5V                    5V                    (아두이노 안에 저항)
   │                     │
 [10kΩ]                [버튼]                 핀 ── [버튼] ── GND
   │                     │
  핀 ●                  핀 ●                  pinMode(핀, INPUT_PULLUP);
   │                     │
 [버튼]                [10kΩ]                 안 누름 = 1
   │                     │                    누름   = 0
  GND                   GND

 안 누름 = 1            안 누름 = 0
 누름   = 0            누름   = 1
```

<br>

## 9. 네오픽셀

<br>

### 특징

선 하나로 LED 여러 개의 색을 하나하나 따로 바꿀 수 있는 LED예요. LED마다 작은 칩이 들어 있어서 신호를 다음 LED로 차례대로 넘겨줘요.

```
 아두이노 10번 ──▶ [LED0] ──▶ [LED1] ──▶ [LED2] ── ... ──▶ [LED7]
```

<br>

### 연결

| 네오픽셀 핀 | 연결 |
|---|---|
| DIN (신호 입력) | 아두이노 디지털 핀 (예: 10번) |
| 5V | 5V |
| GND | GND |

<br>

### 코드

```cpp
#include <Adafruit_NeoPixel.h>
Adafruit_NeoPixel strip(8, 10, NEO_GRB + NEO_KHZ800);  // 8개, 10번 핀

strip.begin();
strip.setBrightness(50);                          // 밝기 (0 ~ 255)
strip.setPixelColor(0, strip.Color(255, 0, 0));   // 0번 LED를 빨강으로
strip.show();                                     // show()를 해야 실제로 바뀜
```

- 라이브러리 매니저에서 "Adafruit NeoPixel"을 먼저 설치해야 해요.
- 밝게 켤수록 전기를 많이 써서, 밝기는 50 정도로 낮춰 쓰는 게 좋아요.

<br>

## 보드에 업로드하는 방법

<br>

### 아두이노 IDE

1. `.ino` 파일을 열어요.
2. 위쪽에서 보드는 Arduino Uno, 포트는 COM3을 골라요.
3. 업로드 버튼(→)을 누르거나 `Ctrl + U`를 눌러요.

<br>

### arduino-cli

```bash
arduino-cli compile --upload -b arduino:avr:uno -p COM3 "스케치 폴더 경로"
```

시리얼 모니터가 열려 있으면 포트를 쓰고 있어서 업로드가 안 될 수 있어요. 이때는 시리얼 모니터를 닫고 다시 해요.
